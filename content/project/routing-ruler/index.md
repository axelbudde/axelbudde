**Routing Ruler** is a commercial freemium SaaS application for airline fare routing rule analysis, built entirely in R Shiny.

The tool parses complex, heterogeneous rule sets from multiple industry data sources (ExpertFlyer, KVS Tool, Amadeus GDS) and generates all compliant flight routing combinations — applying multi-dimensional constraint logic across stopover limits, transfer rules, IATA geographic zones, and carrier restrictions.

### Features

- Multi-source rule parsing (ExpertFlyer, KVS Tool, Amadeus GDS formats auto-detected)
- Combinatorial routing generation across all valid itineraries
- EgoTrip mode: instant compliance verification for user-specified routings
- Carrier and alliance filtering (Star Alliance, Oneworld, SkyTeam)
- User-centered interface designed for non-technical users navigating expert-domain rule systems
- Freemium model with premium subscription tier

### Technical

Full end-to-end product ownership: algorithm design, development, cloud deployment, and commercial subscription management.
